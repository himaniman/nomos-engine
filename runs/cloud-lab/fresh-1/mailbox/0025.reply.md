HYPOTHESIS: A dig is a CLAIM with its own clock. When the wave leads the agent into a wall face it touches (the face's value beats the agent's own cell, read via argmax8(here, value)), that face gets claimed. The claim keeps it bright enough to keep pressing, so the agent sticks with one wall long enough to chip it. That is #16's win (larder dropped: neutral). But an age ticks on every claimed face whatever happens, and at full age the claim dies and the face is SPENT: habituated, with its rim hope dimmed for a few hundred ticks. So a dead dig lets the agent go instead of looping round one rock, and the world-16 pocket stops pulling it back to faces that never gave. A seen morsel a few cells away still outshines a claim, so commitment does not steal it from food.
