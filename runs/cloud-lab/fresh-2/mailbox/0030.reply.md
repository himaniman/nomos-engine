HYPOTHESIS: A `reach` flood marks the region the agent can walk to without pressing, and `hope` carries the best unspent source (unvisited smell, frontier, seen morsel) through it. When a sealed or spent pocket has no hope left, the one winning face beside it (the grain/crest winner, gated by leak and bad) becomes a strong source that skips the wall's damping and grows with work, so the agent commits and digs through one face instead of shuttling and chipping at several. In open ground hope stays up and the law behaves like #23.
PREDICTION: 34.0
```nomos
channel source
channel solid
channel free
channel thing
channel here
channel bad
channel leak
channel value
channel trail
channel injection
channel nbmax
channel aim
channel work
channel thin
channel grain
channel face
channel crest
channel probe
channel reach
channel hope
channel dig
rule seed:
  when grain <= 0
  set grain = uniform(0.001, 1)
rule walk:
  when 1
  set trail = max(here, 0.91 * max8(here), 0.997 * trail)
rule calc_thin:
  when 1
  set thin = max(shift(free, 1, 0) * (1 - shift(solid, -1, 0)), shift(free, -1, 0) * (1 - shift(solid, 1, 0)), shift(free, 0, 1) * (1 - shift(solid, 0, -1)), shift(free, 0, -1) * (1 - shift(solid, 0, 1)))
rule calc_face:
  when 1
  set face = solid * thin * leak * (1 - bad) * (0.4 + 0.6 * grain)
rule calc_crest:
  when 1
  set crest = max(face, 0.93 * max8(crest))
rule inject:
  when 1
  set injection = max(thing, source * (0.74 - 0.82 * trail)) * (0.83 - bad) / (1 + 0.83 * sum8(solid))
# Reach: the region the agent can walk to without pressing (flood from here, stopped by solid).
rule calc_reach:
  when 1
  set reach = max(here, 0.97 * max8(reach)) * (1 - solid)
rule calc_hope:
  when 1
  set hope = max(max(thing, source * (1 - trail)) * (1 - bad), 0.97 * max8(hope)) * where(reach > 0.01, 1, 0)
# Dig: in a hopeless region, the local winner face beside it becomes a source, more as its work grows.
rule calc_dig:
  when 1
  set dig = solid * where(face >= crest - 0.000001, 1, 0) * where(face > 0, 1, 0) * max8(reach) * clamp(1 - 15 * max8(hope), 0, 1) * (0.35 + 0.4 * work)
rule calc_nbmax:
  when 1
  set nbmax = max8(value)
rule calc_aim:
  when 1
  set aim = max8(here) * (1 - here) * where(value >= max8(here * nbmax) - 0.000001, 1, 0) * where(max8(here * nbmax) > 0, 1, 0)
rule effort:
  when 1
  set work = min(1, 0.68 * work + 0.03 * aim * solid)
rule calc_probe:
  when 1
  set probe = where(face > 0, 1, 0) * (face * (0.06 * clamp(1 - 1.4 * trail, 0, 0.56) + 0.3 * work) + 0.05 * where(face >= crest - 0.000001, 1, 0))
rule wave:
  when 1
  set value = max(dig, max(injection, probe, 0.94 * max4(value), 0.8161 * max8(value)) * (1 - solid * (1.3 - leak)) * (1 - 0.9 * bad))
```
