HYPOTHESIS: The pocket agent paces because the winner-face pull never weakens, so a stone face pressed twenty times still wins and the face that would give gets no effort. A new place-memory channel `dud` builds up where effort is spent on a cell that stays solid and fades very slowly; it multiplies the face score, so the crest passes the win to the next face (inhibition of return for presses, not footsteps), and the winner pull is gated by the taught leak. Fewer idle presses and faster escapes from enclosures mean more meals on pocket worlds, with open-ground foraging unchanged.
PREDICTION: 35.6
```nomos
channel source
channel solid
channel free
channel thing
channel here
channel bad
channel leak
channel value
channel trail
channel confinement
channel injection
channel nbmax
channel aim
channel work
channel dud
channel thin
channel grain
channel face
channel crest
channel probe
rule seed:
  when grain <= 0
  set grain = uniform(0.001, 1)
rule walk:
  when 1
  set trail = max(here, 0.91 * max8(here), 0.997 * trail)
rule calc_conf:
  when 1
  set confinement = sum8(solid)
rule calc_thin:
  when 1
  set thin = max(shift(free, 1, 0) * (1 - shift(solid, -1, 0)), shift(free, -1, 0) * (1 - shift(solid, 1, 0)), shift(free, 0, 1) * (1 - shift(solid, 0, -1)), shift(free, 0, -1) * (1 - shift(solid, 0, 1)))
# Dud: effort spent on a cell that is still solid accumulates here and fades very slowly.
rule calc_dud:
  when 1
  set dud = min(1, 0.9995 * dud + 0.12 * work * solid * (1 - free))
# Face score: thin, leaky, not poisoned, not a known dud, ranked by grain.
rule calc_face:
  when 1
  set face = solid * thin * leak * (1 - bad) * (1 - dud) * (0.4 + 0.6 * grain)
rule calc_crest:
  when 1
  set crest = max(face, 0.93 * max8(crest))
rule inject:
  when 1
  set injection = max(thing, source * (0.74 - 0.82 * trail)) * (0.83 - bad) / (1 + 0.83 * confinement)
rule calc_nbmax:
  when 1
  set nbmax = max8(value)
rule calc_aim:
  when 1
  set aim = max8(here) * (1 - here) * where(value >= max8(here * nbmax) - 0.000001, 1, 0) * where(max8(here * nbmax) > 0, 1, 0)
rule effort:
  when 1
  set work = min(1, 0.68 * work + 0.03 * aim * solid)
# Probes: faint faces + work, and a winner pull gated by how leaky the face is believed to be.
rule calc_probe:
  when 1
  set probe = where(face > 0, 1, 0) * (face * (0.06 * clamp(1 - 1.4 * trail, 0, 0.56) + 0.3 * work) + 0.05 * clamp(2 * leak, 0, 1) * where(face >= crest - 0.000001, 1, 0))
rule wave:
  when 1
  set value = max(injection, probe, 0.94 * max4(value), 0.8161 * max8(value)) * (1 - solid * (1.3 - leak)) * (1 - 0.9 * bad)
```
