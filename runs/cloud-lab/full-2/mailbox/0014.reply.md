HYPOTHESIS: Bold axis: change the PHYSICS of exploration, not its weights. Every law so far plans exploration with a max-wave, which only ever sees the single best frontier cell, so roominess had to be bolted on to say how much unknown lies beyond it. Here exploration is a HARMONIC potential — each cell takes the discounted MEAN of its neighbours (0.99*avg8, bounded: weights sum below one, no saturation cliff) clamped at frontier sources — so many frontier cells together pull harder than one crack and the field's gradient points at the mass of the unknown; food keeps its own Bellman max-wave (sources with the frontier marks subtracted, lingering), and the agent follows the larger of the two. Frustration conductance and heading momentum are kept (robust on the pocket and town worlds, 20/20 immortal in #9/#13); roominess and the trail are dropped because the harmonic field replaces the first and momentum the second.
PREDICTION: 28.0
```nomos
channel source
channel thing
channel solid
channel free
channel here
channel bad
channel leak
channel value
channel unk
channel front
channel confinement
channel dwell: init 0
channel crowd: init 0
channel recent: init 0
channel momentum
channel conduct
channel morsel: init 0
channel foodplan: init 0
channel lure: init 0
channel plan

rule recency:
  when 1
  set recent = max(here, 0.95 * recent)
rule heading:
  when 1
  set momentum = max(shift(here, 1, 0) * shift(recent, 2, 0), shift(here, -1, 0) * shift(recent, -2, 0), shift(here, 0, 1) * shift(recent, 0, 2), shift(here, 0, -1) * shift(recent, 0, -2), shift(here, 1, 1) * shift(recent, 2, 2), shift(here, -1, -1) * shift(recent, -2, -2), shift(here, 1, -1) * shift(recent, 2, -2), shift(here, -1, 1) * shift(recent, -2, 2))
rule dwell_time:
  when 1
  set dwell = min(1, 0.998 * dwell + 0.02 * here)
rule frustration:
  when 1
  set crowd = 0.5 * dwell + 0.5 * avg8(crowd)
rule unknown:
  when 1
  set unk = (free < 0.2) * (solid < 0.5)
rule frontier:
  when 1
  set front = unk * (max8(free) > 0.5)
rule calc_conf:
  when 1
  set confinement = sum8(solid)
rule conductance:
  when 1
  set conduct = 1 - solid * (1 - min(1, leak * (1 + 3 * crowd)))

# FOOD only (the harness's 0.12 frontier marks taken out), lingering, erased under the agent
rule food_memory:
  when 1
  set morsel = max(source - 0.12 * front, thing, 0.99 * morsel) * (1 - here) * (1 - max8(here)) * (1 - bad)
# food is planned by Bellman: the single best target, discounted by distance
rule food_wave:
  when 1
  set foodplan = max(morsel / (1 + 0.5 * confinement * (1 - crowd)), max(0.94 * max4(foodplan), 0.916214 * max8(foodplan))) * conduct

# EXPLORATION is a harmonic potential: a cell takes the discounted MEAN of its neighbours, so many
# frontier cells together pull harder than one — the mass of the unknown, not its nearest crack
rule lure_field:
  when 1
  set lure = max(0.3 * front / (1 + 0.5 * confinement * (1 - crowd)), 0.04 * unk, 0.99 * avg8(lure)) * conduct

rule combine:
  when 1
  set plan = max(foodplan, lure)
rule commit:
  when 1
  set value = plan * (1 + 0.1 * momentum)
```
